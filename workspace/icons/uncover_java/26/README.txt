Script 8: Tepo sliro

1.png / 1.svg = “Tepo sliro” adalah falsafah Jawa tentang kemampuan menempatkan diri.
2.png / 2.svg = Artinya, kita belajar memahami perasaan orang lain sebelum bertindak.
3.png / 3.svg = Sebelum berkata keras, bayangkan jika kata itu ditujukan kepada diri kita.
4.png / 4.svg = Sebelum merendahkan orang lain, bayangkan jika kita berada di posisinya.
5.png / 5.svg = Falsafah ini mengajarkan empati dalam kehidupan sehari-hari.
6.png / 6.svg = Orang yang memiliki tepo sliro tidak mudah menyakiti hanya karena merasa benar.
7.png / 7.svg = Ia tahu bahwa setiap manusia punya perasaan, beban, dan cerita yang tidak selalu terlihat.
8.png / 8.svg = Karena hidup akan lebih damai ketika manusia saling menjaga hati.
