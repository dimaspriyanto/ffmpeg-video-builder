Script 13: Adigang adigung adiguno

1.png / 1.svg = “Adigang adigung adiguno” adalah falsafah Jawa yang mengingatkan manusia agar tidak menyombongkan kekuatan, kedudukan, dan kepandaian.
2.png / 2.svg = Adigang berarti mengandalkan kekuatan.
3.png / 3.svg = Adigung berarti mengandalkan kebesaran atau jabatan.
4.png / 4.svg = Adiguno berarti mengandalkan kepintaran.
5.png / 5.svg = Ketiganya bisa membuat manusia lupa diri jika tidak disertai kerendahan hati.
6.png / 6.svg = Orang yang kuat, berkuasa, atau pintar seharusnya semakin bijak, bukan semakin merendahkan orang lain.
7.png / 7.svg = Falsafah ini mengajarkan bahwa kelebihan adalah amanah, bukan alasan untuk sombong.
8.png / 8.svg = Karena manusia yang benar-benar luhur tidak perlu meninggikan diri dengan mengecilkan orang lain.
