Script 11: Ono dino ono upo

1.png / 1.svg = “Ono dino ono upo” adalah falsafah Jawa yang berarti selama masih ada hari, selalu ada rezeki.
2.png / 2.svg = Ungkapan ini mengajarkan manusia agar tidak mudah putus asa dalam menjalani hidup.
3.png / 3.svg = Rezeki tidak selalu datang dalam bentuk uang yang besar.
4.png / 4.svg = Kadang rezeki hadir sebagai kesehatan, kesempatan, bantuan, atau jalan keluar yang tidak disangka.
5.png / 5.svg = Falsafah ini bukan mengajak kita bermalas-malasan dan hanya menunggu nasib.
6.png / 6.svg = Justru ia mengingatkan agar kita tetap bergerak, karena setiap hari membawa kemungkinan baru.
7.png / 7.svg = Selama kita masih berusaha, selalu ada harapan yang bisa tumbuh.
8.png / 8.svg = Karena hidup tidak berhenti hanya karena hari ini terasa sulit.
