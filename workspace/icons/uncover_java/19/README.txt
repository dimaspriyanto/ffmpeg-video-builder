Script 1: Mikul dhuwur mendhem jero

1.png / 1.svg = “Mikul dhuwur mendhem jero” adalah falsafah Jawa tentang menghormati orang tua, keluarga, dan leluhur.
2.png / 2.svg = Mikul dhuwur berarti mengangkat kebaikan mereka setinggi-tingginya.
3.png / 3.svg = Mendhem jero berarti menyimpan kekurangan mereka sedalam-dalamnya.
4.png / 4.svg = Falsafah ini bukan mengajarkan kita untuk menutup kebenaran.
5.png / 5.svg = Tetapi mengajarkan agar kita tidak mudah membuka aib orang yang telah berjasa dalam hidup kita.
6.png / 6.svg = Setiap manusia pasti punya kekurangan, termasuk orang yang kita hormati.
7.png / 7.svg = Namun, kebijaksanaan lahir ketika kita mampu mengingat kebaikan lebih besar daripada kesalahan.
8.png / 8.svg = Karena menghormati asal-usul adalah bagian dari menjaga keluhuran diri sendiri.
