Script 9: Ngluruk tanpo bolo, menang tanpo ngasorake

1.png / 1.svg = “Ngluruk tanpo bolo, menang tanpo ngasorake” adalah falsafah Jawa tentang kemenangan yang beradab.
2.png / 2.svg = Ngluruk tanpo bolo berarti maju tanpa harus membawa banyak kekuatan.
3.png / 3.svg = Menang tanpo ngasorake berarti menang tanpa merendahkan lawan.
4.png / 4.svg = Falsafah ini mengajarkan bahwa kemenangan sejati tidak harus penuh kesombongan.
5.png / 5.svg = Orang yang benar-benar kuat tidak perlu mempermalukan orang lain untuk terlihat hebat.
6.png / 6.svg = Ia mampu menyelesaikan masalah dengan wibawa, bukan dengan pamer kuasa.
7.png / 7.svg = Dalam hidup, menang saja tidak cukup jika cara mencapainya merusak martabat.
8.png / 8.svg = Karena kemenangan paling mulia adalah ketika kita tetap menjaga kehormatan diri dan orang lain.
