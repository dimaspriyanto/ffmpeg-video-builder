Script 2: Sepi ing pamrih, rame ing gawe

1.png / 1.svg = “Sepi ing pamrih, rame ing gawe” adalah falsafah Jawa tentang bekerja dengan tulus.
2.png / 2.svg = Sepi ing pamrih berarti tidak selalu mengharapkan pujian atau balasan.
3.png / 3.svg = Rame ing gawe berarti tetap rajin berbuat dan bekerja nyata.
4.png / 4.svg = Dalam hidup, tidak semua kebaikan harus diumumkan.
5.png / 5.svg = Tidak semua usaha harus dilihat banyak orang.
6.png / 6.svg = Orang yang memahami falsafah ini bekerja bukan karena ingin dipuji, tetapi karena sadar akan tanggung jawabnya.
7.png / 7.svg = Ia tetap bergerak meski tidak mendapat sorotan.
8.png / 8.svg = Karena ketulusan sejati terlihat dari kebaikan yang tetap dilakukan meski tidak ada yang melihat.
