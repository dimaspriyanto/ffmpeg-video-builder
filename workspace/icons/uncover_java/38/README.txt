Script 20: Kalah cacak menang cacak

1.png / 1.svg = “Kalah cacak menang cacak” adalah falsafah Jawa yang mengajarkan keberanian untuk mencoba.
2.png / 2.svg = Artinya, kalah dicoba, menang juga dicoba.
3.png / 3.svg = Dalam hidup, banyak orang gagal bukan karena tidak mampu, tetapi karena tidak pernah berani mulai.
4.png / 4.svg = Rasa takut sering membuat kesempatan hilang sebelum diperjuangkan.
5.png / 5.svg = Falsafah ini mengingatkan bahwa hasil tidak selalu bisa dipastikan dari awal.
6.png / 6.svg = Yang penting adalah berani melangkah dengan perhitungan dan kesungguhan.
7.png / 7.svg = Kalau berhasil, kita mendapat hasil; kalau gagal, kita mendapat pelajaran.
8.png / 8.svg = Karena hidup sering memberi jalan kepada orang yang berani mencoba, bukan hanya kepada orang yang menunggu sempurna.
