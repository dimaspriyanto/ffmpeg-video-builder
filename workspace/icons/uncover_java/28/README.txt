Script 10: Eling lan waspodo

1.png / 1.svg = “Eling lan waspodo” adalah falsafah Jawa tentang kesadaran dan kehati-hatian dalam hidup.
2.png / 2.svg = Eling berarti selalu ingat kepada nilai, asal-usul, dan tujuan hidup.
3.png / 3.svg = Waspodo berarti tidak lengah menghadapi godaan, perubahan, dan bahaya.
4.png / 4.svg = Manusia sering jatuh bukan karena tidak punya kemampuan, tetapi karena lupa diri.
5.png / 5.svg = Ketika seseorang lupa diri, ia mudah terbawa nafsu, pujian, dan kekuasaan.
6.png / 6.svg = Falsafah ini mengingatkan kita untuk tetap sadar dalam setiap keadaan.
7.png / 7.svg = Saat senang jangan berlebihan, dan saat susah jangan kehilangan arah.
8.png / 8.svg = Karena orang yang eling lan waspodo akan lebih mampu menjaga dirinya dari kehancuran.
