Script 9: Aja nganti ilang jawane

1.png / 1.svg = “Aja nganti ilang jawane” adalah nasihat Jawa agar manusia tidak kehilangan tata krama dan rasa kemanusiaan.
2.png / 2.svg = Jawa di sini bukan hanya soal asal daerah.
3.png / 3.svg = Maknanya lebih dalam, yaitu menjaga unggah-ungguh, sopan santun, dan kehalusan budi.
4.png / 4.svg = Orang bisa saja pintar, kaya, atau modern, tetapi tetap perlu punya tata krama.
5.png / 5.svg = Kemajuan tidak seharusnya membuat manusia lupa pada nilai luhur.
6.png / 6.svg = Falsafah ini mengingatkan agar kita tetap menghargai orang tua, sesama, dan lingkungan.
7.png / 7.svg = Menjadi modern bukan berarti harus kehilangan akar.
8.png / 8.svg = Karena manusia yang berbudaya adalah manusia yang maju tanpa meninggalkan adab.
