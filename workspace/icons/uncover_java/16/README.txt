Script 8: Sak madyo wae

1.png / 1.svg = “Sak madyo wae” adalah falsafah Jawa yang mengajarkan hidup secukupnya dan tidak berlebihan.
2.png / 2.svg = Tidak semua hal harus dimiliki sebanyak-banyaknya.
3.png / 3.svg = Tidak semua keinginan harus dipenuhi secepat-cepatnya.
4.png / 4.svg = Hidup yang terlalu dikuasai ambisi bisa membuat hati lelah.
5.png / 5.svg = Falsafah ini bukan mengajarkan kita untuk tidak berkembang.
6.png / 6.svg = Tetapi mengingatkan agar manusia tahu ukuran, tahu batas, dan tahu rasa cukup.
7.png / 7.svg = Dengan hidup yang sak madyo, seseorang lebih mudah bersyukur dan tidak mudah iri.
8.png / 8.svg = Karena ketenteraman sering lahir dari hati yang bisa berkata cukup.
