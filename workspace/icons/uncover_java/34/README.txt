Script 16: Deso mowo coro, negoro mowo toto

1.png / 1.svg = “Deso mowo coro, negoro mowo toto” adalah falsafah Jawa tentang menghormati adat dan aturan di setiap tempat.
2.png / 2.svg = Setiap daerah punya cara, kebiasaan, dan nilai yang berbeda.
3.png / 3.svg = Setiap negara atau lingkungan juga punya tata aturan yang harus dijaga.
4.png / 4.svg = Falsafah ini mengajarkan kita agar tidak merasa cara hidup sendiri paling benar.
5.png / 5.svg = Saat masuk ke tempat baru, manusia perlu belajar menyesuaikan diri.
6.png / 6.svg = Menghormati budaya orang lain adalah bagian dari kedewasaan.
7.png / 7.svg = Orang yang bijak tahu kapan harus membawa prinsip dan kapan harus menghargai kebiasaan setempat.
8.png / 8.svg = Karena hidup bersama akan lebih damai jika manusia saling menghormati tata cara masing-masing.
